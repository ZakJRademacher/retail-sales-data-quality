# Executed analysis outputs

All monetary CSV fields ending in `_pence` use integer GBP minor units. Divide by 100 once to display pounds. `analysis.json` records the input fingerprint, metrics, reconciliation checks and report arrays.

The six SQL report CSVs are monthly, countries, products, customer_repeat, exclusion_summary and quality_flags. `exceptions.csv` preserves excluded records with explicit reasons. The full cleaned export and SQLite database are generated by the pipeline and omitted from Git to keep the repository small.

See [the data dictionary](../docs/DATA_DICTIONARY.md) and [method](../docs/METHOD.md) for definitions and limitations.
