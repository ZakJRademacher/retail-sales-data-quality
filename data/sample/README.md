# Cleaned example

`cleaned_example_1000.csv` contains the first 1,000 eligible records in source order. It illustrates the output schema and row lineage; it is not a representative random sample or the population used for published metrics. The full 541,909-row source was processed for the analysis.

Data source: Chen, D. (2015), Online Retail, UCI, DOI 10.24432/C5BW33; downloaded from Kaggle carrie1/ecommerce-data. UCI lists CC BY 4.0. Normalization and eligibility rules are documented in [METHOD.md](../../docs/METHOD.md).
